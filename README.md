# RS-HW — Regime-Switching Short-Rate Dynamics

**A Hidden Markov Approach to Hull–White Estimation on Euro-Area Government Bond Yields**
Klaus Leopold von Moltke · Working paper, 1 October 2026 · [`Paper/main.pdf`](Paper/main.pdf)

Two questions on 378 daily ECB AAA yield curves (2 Jan 2025 – 26 Jun 2026):

- **(a) Detection.** Do regimes inferred blindly by a two-state Gaussian HMM (on daily changes of level, slope and curvature) coincide with 26 monetary-policy, geopolitical, macroeconomic and fiscal events (recorded contemporaneously from 8 April 2026; the ten earlier events were compiled retrospectively) more closely than chance?
  → Exact rotation test, pre-registered primary cell: T_obs = 9 vs. 4.28 expected, **p = 0.1088 — not significant** (diagnosed negative result; all 12 registered cells in `Abgaben/rotationstest.csv`).
- **(b) Estimation.** Do Ornstein–Uhlenbeck / Hull–White parameters of the 3M rate, estimated under the physical measure within each regime, differ beyond estimation uncertainty?
  → σ-ratio crisis/calm **2.66, BCa 95 % [2.22, 3.40]**; mean reversion *a* not identified (crisis interval contains 0). The pre-registered joint claim is therefore not made.

Every estimate and test statistic in the paper, and all tables and the figure, are generated by `Paper/build_exhibits.py` from the files in this repository.

## Reproduction (in this order)

```bash
pip install -r requirements.txt
python Abgaben/01.07.Abgabe.py                     # PCA -> Code/hmm_input_changes.csv
python Abgaben/2026-07-06_M28_erster-HMM-fit.py    # Stage 1 fit (seed 42)
python Abgaben/2026-07-13_M29_BIC-Vergleich.py     # Stage 1 BIC, 1 vs 2 states
python Abgaben/2026-07-24_M29_filtered-vs-smoothed.py
python Abgaben/2026-07-28_M30_crisis-sanity-check.py
python Code/robustheit_startwerte.py               # 24 initialisations
python Code/permutationstest.py                    # rotation test (implementation 1)
python Abgaben/2026-08-27_P1_rotationstest-eigen.py  # rotation test (implementation 2, author)
python Abgaben/2026-09-20_P2_ar1-schaetzung.py     # Stage 2 point estimates + residual diagnostics
python Code/bootstrap_ziehungen.py                 # stored resampling indices (seed 42)
python Code/bootstrap_referenz.py                  # bootstrap, reference implementation
python Abgaben/2026-09-28_P3_bootstrap.py          # bootstrap, second implementation (checks against reference)
python Code/bic_stage2_referenz.py                 # Stage 2 BIC, reference (two computations)
python Abgaben/2026-09-28_P4_bic-stage2.py         # Stage 2 BIC, second implementation (checks against reference)
python Code/einfluss_pruefung.py                   # check of the BCa acceleration with exact influence values
cd Paper && python build_exhibits.py && latexmk -pdf main.tex
```

`build_yields.py` is not part of the chain: the ECB occasionally revises recent observations, so a new download can differ slightly from the file used. `yields.csv` is the exact file used.

Tested on the author's machine (versions in `requirements.txt`) and, by the AI assistant, independently on Linux / Python 3.10 with numpy 2.2.6, pandas 2.3.3, scipy 1.15.3, scikit-learn 1.7.2, hmmlearn 0.3.3, statsmodels 0.15.0: the rotation-test, robustness and reference outputs are byte-identical, the remaining result files agree to ≤ 4·10⁻¹³, the generated `numbers.tex` and tables are identical.

Implementation notes that affect replication in other software: BCa limits use linear interpolation between order statistics (`np.quantile`); the acceleration for the ratios uses the K-sample rule with weights 1/n_k (paper, Section 3.5). R's `boot::boot.ci` computes the acceleration unweighted and therefore gives a different value when the regime sizes differ.

## Event labels

`Code/key_events.csv` uses German descriptions. Labels: `ecb_cut` / `ecb_hike` / `ecb_hold` — ECB rate cut / hike / hold; `fed_cut` / `fed_hold` — Federal Reserve rate cut / hold; `fed_chair_change` — change of Fed chair; `growth_shock` — fiscal or growth surprise; `tariff_shock` — US tariff announcement; `cpi_surprise` — inflation surprise (CPI or PCE); `payroll_surprise` — US payroll surprise; `hormus_start` / `hormus_eskalation` / `hormus_deeskalation` — start / escalation / de-escalation of the Strait of Hormuz conflict.

## Use of AI assistance

The research questions and all registered design decisions are the author's. AI assistance (Anthropic's Claude, the only AI tool used, accessed through the Claude app, Claude Code and Cowork throughout the project) was used for literature search and verification, for methodological suggestions, which the author evaluated and decided on, for parts of the code and for drafting the paper. - Author-written, following task plans prepared by the AI assistant: PCA and Stage 1 fit (`Abgaben/01.07.Abgabe.py`, `M28`, `M29`, `M30`), the rotation test `P1`, the Stage 2 point estimates `P2`.
